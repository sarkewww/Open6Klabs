## 使用方法

```bash
pnpm install

pnpm mock     # 后端 -> http://localhost:8787
pnpm widget   # 挂件 -> http://localhost:5199/widget/amuse/local
pnpm panel    # 面板 -> http://localhost:5174
```

- 控制面板：<http://localhost:5174>
- 挂件：<http://localhost:5199/widget/amuse/local>
